# M002/S03 cloud proof artifacts — SKIPPED

Reason: MERMAID_OSS_ENDPOINT env is unset

This script is MinIO-gated. When MERMAID_OSS_ENDPOINT is unset
or the endpoint is unreachable, the suite short-circuits and
writes this marker instead of producing the 4 artifacts.

To regenerate the proof artifacts on a host with MinIO reachable:

  1. `docker run -d -p 9000:9000 -p 9001:9001 \`
        -e MINIO_ROOT_USER=test -e MINIO_ROOT_PASSWORD=testtest \`
        minio/minio server /data --console-address :9001`
  2. `mc alias set local http://127.0.0.1:9000 test testtest`
  3. `mc mb local/mermaid`
  4. Export the 5 MERMAID_OSS_* env vars (see bin/migrate-to-oss.mjs --help)
  5. `node tests/integration/cloud-proofs/capture-cloud-proofs.mjs`

Generated by `tests/integration/cloud-proofs/capture-cloud-proofs.mjs`.
